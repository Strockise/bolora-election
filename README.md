# বলোড়া হিলফুল ফুজুল — অনলাইন নির্বাচন টুল

ভোটাররা একটি লিংকে ঢুকে Google দিয়ে এক চাপে প্রবেশ করেন, একজন প্রার্থী বাছাই করে ভোট দেন। এক Gmail থেকে একটিই ভোট। কে কাকে ভোট দিয়েছেন তা কোথাও সংরক্ষিত হয় না, শুধু প্রত্যেক প্রার্থীর মোট সংখ্যা বাড়ে।

- মূল লিংক: `https://bolora-hilf-al-fudul.web.app/` — খুললে **ভোটার** ও **অ্যাডমিন** দুটি অপশন আসে।
- প্রতিটি নির্বাচনের আলাদা লিংক থাকে (`…/?e=<কোড>`), অ্যাডমিন প্যানেল থেকে কপি করা যায়। ওই লিংক ছাড়া কেউ সেই নির্বাচনে ভোট দিতে পারে না।

সব কিছু Google-এর বিনামূল্যের Firebase (Spark plan) দিয়ে চলে। ৫০–১০০ জনের নির্বাচনে কোনো খরচ নেই, কার্ডও লাগবে না।

---

## একবারের সেটআপ (প্রায় ১৫ মিনিট)

কম্পিউটারে করা সহজ। যে Gmail দিয়ে মূল অ্যাডমিন হবেন (strockise.official@gmail.com) সেটি দিয়ে লগইন করে নিন।

### ধাপ ১ — Firebase প্রজেক্ট খুলুন
1. https://console.firebase.google.com এ যান → **Create a project**।
2. নাম দিন, যেমন `bolora-election` → Google Analytics **বন্ধ** রাখুন → **Create project**।

### ধাপ ২ — Web app যোগ করে config কপি করুন
1. প্রজেক্টের হোমে **`</>`** (Web) আইকনে চাপুন।
2. Nickname: `election` → **Register app**।
3. যে `firebaseConfig` দেখাবে, সেখান থেকে `apiKey`, `authDomain`, `projectId`, `appId` — এই চারটি মান কপি করে **`public/config.js`** ফাইলের `firebase` অংশে বসান।

```js
firebase: {
  apiKey: "AIza....",
  authDomain: "bolora-election.firebaseapp.com",
  projectId: "bolora-election",
  appId: "1:1234:web:abcd"
}
```

### ধাপ ৩ — Google লগইন চালু করুন
**Build → Authentication → Get started → Sign-in method → Google → Enable** → Support email বাছাই করে **Save**।

### ধাপ ৪ — ডাটাবেস তৈরি করুন
1. **Build → Firestore Database → Create database**।
2. Location: **asia-south1 (Mumbai)** (বাংলাদেশের সবচেয়ে কাছে) → **Start in production mode** → **Create**।
3. **Rules** ট্যাবে যান, সেখানের সব লেখা মুছে এই ফোল্ডারের **`firestore.rules`** ফাইলের পুরো লেখা পেস্ট করুন → **Publish**।

> নিয়মের ফাইলে মূল অ্যাডমিনের ইমেইল `strockise.official@gmail.com` বসানো আছে। বদলাতে চাইলে `firestore.rules` আর `public/config.js` দুই জায়গাতেই বদলাবেন।

### ধাপ ৫ — ওয়েবসাইট অনলাইনে তুলুন (Hosting)
কম্পিউটারে **Node.js** লাগবে (https://nodejs.org থেকে LTS ইনস্টল করুন)। তারপর এই ফোল্ডারে Terminal / Command Prompt খুলে:

```bash
npm install -g firebase-tools
firebase login
firebase deploy --project bolora-election
```

(`bolora-election` এর জায়গায় আপনার আসল Project ID দিন।) শেষে `Hosting URL: https://bolora-election.web.app` দেখাবে — এটাই ভোটারদের লিংক।

## নির্বাচন চালানো

1. **`…web.app/admin`** খুলুন → Google দিয়ে প্রবেশ করুন।
2. **+ নতুন নির্বাচন** → পদের নাম (যেমন “সভাপতি নির্বাচন”) → প্রার্থীদের নাম প্রতি লাইনে একজন → **সংরক্ষণ করুন**।
3. নামগুলো মিলিয়ে নিয়ে **ভোটগ্রহণ শুরু করুন**। (শুরুর পর প্রার্থী তালিকা আর বদলানো যায় না।)
4. **ভোটারদের লিংক** কপি করে WhatsApp/Messenger গ্রুপে পাঠান।
5. প্যানেলে লাইভ দেখবেন কতজন ও কারা ভোট দিয়েছেন।
6. সময় শেষে **ভোটগ্রহণ শেষ করুন** → ফলাফল খুলে যাবে। চাইলে **ফলাফল ভোটারদের দেখান** চালু করুন।
7. পরের পদের জন্য (সহ-সভাপতি, সম্পাদক…) আবার **নতুন নির্বাচন** — আগের প্রার্থী তালিকা এক চাপে কপি করা যায়।

### ভোটার অনুমোদন
কেউ প্রথমবার **ভোটার** হিসেবে Google দিয়ে প্রবেশ করলে তাঁর নাম অ্যাডমিন প্যানেলের **ভোটার** ট্যাবে “অনুমোদনের অপেক্ষায়” তালিকায় আসে। অ্যাডমিন **অনুমোদন দিন** চাপলে তবেই তিনি ভোট দিতে পারবেন। অনুমোদিত ভোটাররা মূল লিংকে ঢুকলেই সব চলমান নির্বাচন দেখতে পান। সদস্যদের Gmail আগে থেকে জানা থাকলে “ইমেইল দিয়ে সরাসরি যোগ করুন” দিয়ে আগেই অনুমোদিত করে রাখা যায়।

### অন্য কাউকে অ্যাডমিন বানানো
**অ্যাডমিন** ট্যাবে তাঁর Gmail লিখে **যোগ করুন**। তিনি `/admin` লিংকে নিজের Gmail দিয়ে ঢুকতে পারবেন। শুধু মূল অ্যাডমিন অন্যদের যোগ/বাদ দিতে পারেন।

## গোপনীয়তা ও নিরাপত্তা কীভাবে নিশ্চিত হয়

- নিয়মগুলো Google-এর সার্ভারে চলে (`firestore.rules`)। ব্রাউজারে কোড বদলে কেউ এগুলো এড়াতে পারবে না।
- ভোট দিলে একসাথে তিনটি কাজ হয়: প্রার্থীর মোট সংখ্যা ঠিক ১ বাড়ে, “এই ব্যক্তি ভোট দিয়েছেন” রসিদ তৈরি হয় (কাকে দিয়েছেন তা ছাড়া), আর একটি ব্যালট বাক্স যাচাই হয় যেটা কেউ পড়তে পারে না। তিনটির একটি না মিললে পুরো ভোট বাতিল।
- রসিদ একবার তৈরি হলে মোছা বা বদলানো যায় না, তাই একই অ্যাকাউন্টে দ্বিতীয় ভোট সম্ভব নয়।
- অ্যাডমিনরাও ভোটের সংখ্যা হাতে বদলাতে পারেন না।
- ফলাফল শুধু ভোটগ্রহণ শেষ হওয়ার পর খোলে। ভোট চলাকালীন কেউই, অ্যাডমিনও, ফলাফল দেখতে পারেন না — এটি সার্ভারের নিয়মে আটকানো।
- একটি সীমা জেনে রাখুন: Firebase প্রজেক্টের মালিক Firebase Console থেকে ভোট চলাকালীন ডাটাবেস সরাসরি দেখতে পারেন। নিরপেক্ষতার জন্য ভোট চলাকালীন Console-এ Firestore খুলে বসে থাকবেন না।

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| Messenger/Facebook থেকে লিংক খুললে Google লগইন হয় না | উপরের ⋮ মেনু → **Open in browser**/Chrome। পাতাতেই এই নির্দেশনা দেখায়। |
| “এই ঠিকানাটি অনুমোদিত নয়” | Authentication → Settings → Authorized domains-এ আপনার ডোমেইন যোগ করুন (web.app আপনিই যুক্ত থাকে)। |
| অ্যাডমিন প্যানেলে “প্রবেশাধিকার নেই” | config.js ও firestore.rules-এ মূল অ্যাডমিনের ইমেইল ঠিক আছে কিনা দেখুন, rules আবার Publish করুন। |
| পাতায় “ডেমো মোড” লেখা দেখায় | `public/config.js`-এ firebase মানগুলো বসানো হয়নি। বসিয়ে আবার `firebase deploy` দিন। |

## ফাইলগুলো

```
public/index.html      পাতা (ভোটার ও অ্যাডমিন একই অ্যাপ)
public/config.js       ← শুধু এটি পূরণ করবেন
public/assets/app.js   অ্যাপের কোড
public/assets/app.css  ডিজাইন
firestore.rules        সার্ভারের নিরাপত্তা নিয়ম
firebase.json          Hosting সেটিং
```
